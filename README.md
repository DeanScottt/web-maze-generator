# Maze Generator and Solver

## Site link
[![Netlify Status](https://api.netlify.com/api/v1/badges/86c2a3e3-e514-46ac-b57d-800108031f04/deploy-status)](https://wilsons-algorithm.netlify.app/)

## Details
Generates a large maze using Wilson's algorithm to produce a uniform layout distribution.\
No loops or isolated areas are created, making a basic DFS viable.

The code uses a BFS, mostly because it looks nice,
but I may add more search algorithms in the future.
